# machine/ — the new program

Tejas's trading idea in plain words → questions only where it is unclear → tested on 2016–2023 gold → a report in
rupees. The plan is `plan/README.md`; the prompts that build each folder are in `plan/likhith.md`.
New code here never imports from `old/`.

## Run the tests

```
.venv\Scripts\python -m pytest -q           # Windows (macOS / Linux: .venv/bin/python)
```

Tests marked `@pytest.mark.data` need the 3 price files; tests marked `@pytest.mark.mt5` need Windows + MetaTrader5.
Both skip themselves when their need is missing. GitHub runs the tests and a secret scan on every push
(`.github/workflows/tests.yml`). New PC: `docs/SETUP.md`.
